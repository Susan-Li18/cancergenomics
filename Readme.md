# Cancer Genomics: Somatic Variant Analysis

This project analyzes paired tumor (`tumor`) and normal (`normal`) sequencing data on a Slurm cluster. The workflow covers read quality control, read cleaning, alignment, BAM processing, base quality score recalibration, somatic variant calling, VEP annotation, and visualization in R.

This README describes the scripts and files currently present in the workspace. The project directory is `/data/users/jli/cancergenomics`, the Slurm partition is `pibu_el8`, and VEP annotation uses GRCh38.

## Scripts and Execution Order

| Step | Script | Purpose and main outputs |
|---|---|---|
| 01 | `scripts/01_run_fastqc.sh` | Run FastQC on raw paired-end reads from normal and tumor samples |
| 02 | `scripts/02_run_fastp.sh` | Clean reads; produce `*.R1_clean.fq.gz`, `*.R2_clean.fq.gz`, and HTML/JSON reports |
| 03 | `scripts/03_run_fastqc_clean.sh` | Run FastQC on cleaned reads and generate a MultiQC report |
| 04 | `scripts/04_run_bwamem2.sh` | Align reads with BWA-MEM2, add read groups, and produce `*_aligned.bam` |
| 05 | `scripts/05_sort_bam.sh` | Sort alignments by coordinate and index `*_sorted.bam` |
| 06 | `scripts/06_markduplicates.sh` | Mark duplicates; produce `*_marked.bam`, duplication metrics, and BAM indexes |
| 07 | `scripts/07_collectmultiplemetrics.sh` | Collect BAM metrics and generate a MultiQC report |
| 08 | `scripts/08_run_bqsr.sh` | Generate `*_recal.table` using known variant sites |
| 09 | `scripts/09_run_appbqsr.sh` | Apply recalibration tables and produce `*_recal.bam` |
| QC 01 | `scripts/QC_01_run_flagstat.sh` | Run samtools flagstat on supplied recalibrated BAM files; write statistics to job standard output |
| QC 02 | `scripts/QC_02_run_collecthsmetrics.sh` | Calculate hybrid-selection metrics for supplied recalibrated BAM files |
| 10 | `scripts/10_run_mutect2.sh` | Call somatic variants from paired samples; produce `somatic.vcf.gz` |
| 11 | `scripts/11_run_filtermutectcall.sh` | Run FilterMutectCalls; produce `somatic.filtered.vcf.gz` |
| 12 | `scripts/12_run_bcftools.sh` | Extract PASS variants into `somatic.filtered.PASS.vcf.gz` and create a tabix index |
| 13 | `scripts/13_download_vep.sh` | Prepare the VEP 116 container and GRCh38 cache |
| 14 | `scripts/14_run_vep.sh` | Annotate the independent `cancer_variants.vcf` input using `--pick`, SIFT, PolyPhen, and protein domains |
| 15 | `scripts/15_vep_somatic.sh` | Annotate PASS somatic variants with VEP and ClinVar, filter annotations, and summarize consequences |
| 16 | `scripts/16_run_rscript.sh` | Load the R module and run `scripts/16_visulization.R` to save figures |

Current workflow connections:

**Scripts 01–09: Data processing and quality control.** Script 01 checks raw read quality with FastQC; script 02 cleans reads with fastp; script 03 checks cleaned read quality and summarizes reports with MultiQC; script 04 aligns reads to the reference genome; script 05 sorts and indexes BAM files; script 06 marks duplicate reads; script 07 collects alignment quality metrics; script 08 builds base quality recalibration tables; and script 09 applies those tables to produce recalibrated BAM files.

**Supplementary QC scripts: Statistics after data processing and quality control.** `QC_01_run_flagstat.sh` summarizes alignment statistics, including mapped reads and properly paired reads. `QC_02_run_collecthsmetrics.sh` reports exome capture and coverage metrics. These statistics help assess the processed data before variant calling.

**Scripts 10–12: Variant calling.** Script 10 calls somatic variants from paired tumor and normal BAM files using Mutect2. Script 11 applies FilterMutectCalls to flag variants that fail filtering criteria. Script 12 extracts and indexes variants marked PASS for downstream annotation.

**Scripts 13–16: Annotation and visualization.** Script 13 downloads the VEP container and prepares the GRCh38 cache. Script 14 tests VEP on a small VCF file. Script 15 performs VEP annotation on the PASS variant calling results, adds ClinVar information, filters annotations, and summarizes consequences. Script 16 generates analysis figures from the complete VEP annotation table.

Implementation note: script 10 and both supplementary QC scripts currently read the supplied recalibrated BAM files in `01_raw_data/VAR_CALLING/alignments/`. Script 14 is a test branch; script 15 reads the output of script 12 directly.

## Submitting and Monitoring Jobs

Submit jobs from the project root, for example:

```bash
cd /data/users/jli/cancergenomics
sbatch scripts/16_run_rscript.sh
```
Monitoring jobs, for example:
```bash
squeue -u jli
```
Each script is submitted separately; there is currently no single workflow launcher. Run scripts in dependency order and confirm that upstream jobs succeed before starting downstream jobs.
